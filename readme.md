# RobloxVisuals (DoctorHack Visuals)

Универсальный клиентский визуальный скрипт (Visual Hub) для Roblox. Проект создан для кастомизации графики, добавления визуальных эффектов (аур), медиа-функций, оптимизации и удобных утилит без использования читов.

---

## ✨ Функционал
* **Ауры:** 7 стилей визуального оформления (частицы, орбиты, спираль, кольца, нимб, пламя, сияние), гибкая настройка цветов и шлейфы.
* **Медиа-центр:** Встроенный плеер для `.webm` видео, аудиоплеер с эквалайзером и быстрый доступ к популярным сервисам.
* **Производительность:** Снятие или настройка лимита FPS, упрощение графики, отключение теней и частиц, очистка памяти (RAM).
* **Мир и Окружение:** Fullbright (удаление темноты), фиксация времени суток, погодные эффекты (снег, дождь, светлячки), цветокоррекция и виньетка.
* **Игроки (ESP):** Подсветка игроков (Highlight), никнеймы, дистанция, полоски здоровья, командные цвета и режим наблюдения (*Spectate*).
* **Камера и Интерфейс:** Настройка FOV, зума, Shift Lock и полное скрытие стандартного интерфейса для скриншотов.
* **Помощники:** Экранный HUD (FPS, пинг, RAM, координаты XYZ), анти-AFK и утилиты для работы с серверами.
* **Настройки:** Кастомизация интерфейса (цвета, прозрачность, масштаб, размытие) и сохранение конфигов в JSON.

## 🚀 Установка и запуск

### Способ 1: Через инжектор (для игры)
Запустите ваш инжектор в игре и выполните загрузку скрипта:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/CheatsAndHacks2/RobloxVisuals/main/OpenSourse"))()
```

### Способ 2: Для своего плейса в Roblox Studio
*Поскольку Roblox Studio блокирует функцию `loadstring` на клиенте, использовать ссылку напрямую там нельзя.*
1. Откройте файл `OpenSourse` на GitHub и скопируйте весь его исходный код целиком.
2. В Roblox Studio создайте `LocalScript` внутри `StarterPlayerScripts` или `StarterGui`.
3. Вставьте скопированный код прямо в этот скрипт.
4. В настройках игры (`Home` -> `Game Settings` -> `Security`) убедитесь, что разрешены HTTP-запросы (`Enable HTTP Requests`), если это требуется для внешних текстур.
